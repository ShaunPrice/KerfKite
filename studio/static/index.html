Text & 3D contours

Router mode follows the font outline at its assigned depth. Y rotation creates varying Z depths. Use the V-carve operation for V-bit lettering, or the raised/recessed buttons for a filled relief. Solid STL export uses the selected depth as extrusion height.

Polygon & gear settings

Polygon uses Width/Height. Involute spur gears: use matching module and pressure angle for a pair. Centre distance = module × (teeth A + teeth B) / 2. Tooth thinning is per gear at the pitch circle; pair thinning adds to backlash. Hole cuts first. Select a gear to edit its teeth/module directly. Gear drag-resizing is locked to preserve tooth geometry. Use Outside/Inside profile CAM for cutter or kerf compensation. Line mode follows the contour directly. Physical gear meshing still needs testing.

Files & receiver uploads

Laser image engraving
3D relief · image / STL

Uses X/Y, Width/Height and cutter/stepover settings. White is stock top; black is maximum depth. Image maps go up to 1024 points a side with the compiled extension (256 without); STL and artwork maps up to 128. Large maps need a wider stepover to stay within 100,000 path points. Nonzero allowance creates a roughing surface. Clear cutter overhang at map edges. STL is viewed from +Z; undercuts cannot be machined.
