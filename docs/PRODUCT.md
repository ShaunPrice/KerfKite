# Feature and acceptance matrix

This matrix describes the software workflows covered by the feature guides and simulator. The per-feature guides record accepted inputs and tests. Hardware measurements and tests with vendor controllers are tracked separately.

| Workflow | Implemented in Studio | Scope and remaining work |
| --- | --- | --- |
| 2D design and layers | Shape properties, rotation pivots, freely placed or snapped lines, intersection trim, flat layout groups, layer colours and settings, visibility and output toggles, ordering, align and distribute, offsets and booleans, [dog-bone corners, inlays and nesting](JOINERY.md), and [project wizards](PROJECT-WIZARDS.md) for a finger-jointed box, dividers and a sign blank | Group translation keeps machining settings on each member. Nested group hierarchies and full document constraints are open. |
| Solid and surface CAD | Driven sketches with geometric constraints, tangent fillets and Bézier edges, two-section parametric lofts, solid histories, linked CAM contours/reliefs, assembly datum mates, multi-patch surface trim/sewing, STL and STEP | STEP carries exchanged geometry. Imported feature histories, arbitrary surface networks, general curve-to-curve solvers and continuous full-machine collisions remain open. [Solid CAD](SOLID-CAD.md) · [Surfaces and STEP](SURFACES-STEP.md) |
| Keyboard CAD and macros | Command palette, 2D/3D source editor, measured geometry previews, script features, seven programmable starters, macro file exchange and viewport shortcuts | See the [supported language](CAD-SCRIPTING.md) and [macro programming guide](CAD-MACROS.md). Scripted solids export as STL. |
| Assistant workshop | Isolated Studio editor controlled by MCP, geometry calculations, reusable skill and optional paired or hosted adapters | Hosted assistant setup requires a reachable authenticated endpoint. [Setup](MCP.md) |
| Text and identification | Bundled outline fonts, TTF/OTF, browser-supported local font discovery, original single-line Workshop Mono, straight/vertical/curved layouts, rotation and depth, serial labels, Code 39 and QR | Single-line face covers printable ASCII. Complex-script shaping and variable-data spreadsheets remain open. Printed or engraved code readability requires a sample. [Production labels](LABELS.md) |
| Interchange | Reviewed LightBurn vectors/settings, SVG, DXF, selected PDF pages, G-code, HP-GL, LinuxCNC settings, STL, STEP and portable Studio projects | Fidelity depends on the feature subset. Native proprietary cutter projects, universal SVG/CSS rendering, and lossless LightBurn round trips remain open. [Program formats](PROGRAM-IMPORT.md) · [LightBurn](LIGHTBURN-IMPORT.md) |
| Laser | Vector line, fill and crosshatch, kerf, curved/straight leads, power ramps, perforation, bridges, layer-aware ordering, duplicates, tone and masking, scan direction and overscan | Tune machine-specific power and resulting kerf on stock. [Laser patterns](LASER-PATTERNS.md) · [Image workshop](LASER-WORKSHOP.md) |
| Camera | Capture/import, trace, projective bed registration, centred radial calibration, overlay and independent checkpoint | Physical lens and work-surface accuracy require measurement. Tangential distortion and full intrinsic lens calibration remain open. [Camera registration](CAMERA-REGISTER.md) |
| Router | Line/profile/pocket, stepped and varying-depth work, drilling with pecks, profile ramps and pocket helices, graphical tab placement, V-carving, relief with cutter compensation, stock preview and clamp checks | General engagement-controlled adaptive roughing, full-machine certification and automatic probing or tool changing remain open. Manual tool-change stage files are supported. [Drilling](DRILLING.md) · [Router entry](ROUTER-ENTRY.md) |
| Knife and rotary | Drag-knife offset/swivel compensation, HP-GL cutting designs, rotary mapping, seam checks, laser exposure passes and cylindrical router depth paths | Live rotary streaming targets supported independent rotary controllers. Arbitrary simultaneous multiaxis surfacing and powered tangential knives remain open. [Rotary profiles and simulation](ROTARY.md) |
| Job preparation | 1,768 stock templates, local libraries, a [tool library](TOOL-LIBRARY.md) with starting feeds and speeds from chip load, materials and sample notebook, material-test grids, projects, file recovery, printing, quotes, timed motion estimates and sample calibration | Verify sample factors on comparable material and motion. A calculated duration is an estimate. |
| Control and setup | Design-profile library, approved-head setup, simulator, manual/keyboard/gamepad pendant and paired native Android pendant through the Studio server | GRBL-family and Marlin live adapters have software tests. Mach and other file-only profiles use the vendor sender. SDK integrations, specialist laser controllers, physical homing, head offsets, probing and accessory commissioning need separate support. [Controller matrix](PROTOCOLS.md) |
| Delivery | Desktop installers, SBC packages, a portable offline editor, HTTPS editor/receiver and signed Android Pocket with named projects | Hardware acceptance is separate for each installation. See [platform validation](PLATFORMS.md) and [Android](ANDROID.md). |

The local simulator, browser workflows and installer checks provide software evidence. Acceptance on a particular router, laser or knife requires its measured travel, calibration and actual material tests. The supported workflow and format subsets are documented so future contributors can extend them with reproducible fixtures.
