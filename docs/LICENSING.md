## Desktop installers

Studio 0.5.0 includes first-party native desktop window code under MIT. AppKit and WebKit come from macOS. The Linux package depends on the distribution's GTK, PyGObject and WebKitGTK. Windows Setup redistributes Microsoft WebView2 SDK assemblies and the x64 loader from the pinned SDK NuGet package. The installer places the original Microsoft licence and third-party notices beside those files. The Microsoft Evergreen WebView2 Runtime is installed separately and has its own terms. The .NET Framework reference assemblies from the build are excluded from the installer. [Microsoft WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4314.35)


The desktop packages include the first-party portable Studio wheel, its bundled vendor notices, a hash-pinned dependency list and a Go launcher. The launcher ships Go notices under `runtime-notices`. First launch downloads the pinned Astral uv executable after checking the release digest. uv installs a private Python runtime and the listed third-party wheels on the user’s computer. Each downloaded distribution retains its upstream terms. The Android release APK uses a dedicated project signing certificate. [uv licence](https://github.com/astral-sh/uv/blob/0.13.1/LICENSE-MIT) · [Go licence](https://go.dev/LICENSE)

## Geometry and other native dependencies

* **PDF import.** pypdf 7.1.1 is a pure-Python dependency under BSD-3-Clause. The hashed desktop install downloads its unmodified wheel with its upstream licence. [pypdf licence](https://github.com/py-pdf/pypdf/blob/7.1.1/LICENSE)
* **STEP.** The exchange module uses Open CASCADE Technology through `cadquery-ocp-novtk`. The tested 7.9.3.1.1 wheel's metadata says Apache-2.0 for the bindings. Its Mach-O libraries include the **OCCT 7.9.3** kernel under LGPL 2.1 with the Open CASCADE exception. The exception concerns incorporation of material from headers and requires acknowledgement. Redistributing OCCT binaries still carries LGPL obligations. Supply the library licences, applicable corresponding source or compliant distribution arrangement, preserve notices and permit replacement/relinking and debugging of library modifications as the LGPL requires. Retain actual build and patch information corresponding to the binaries. [OCP licence](https://github.com/CadQuery/OCP/blob/master/LICENSE) · [OCCT 7.9.3 licence](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/LICENSE_LGPL_21.txt) · [OCCT exception](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/OCCT_LGPL_EXCEPTION.txt)
* **Additional STEP-wheel libraries.** The inspected no-VTK macOS wheel contained FreeImage 3.18, LibRaw, FreeType, OpenEXR, Imath, Lerc, libjpeg, JPEG XR, Little CMS, OpenJPEG/OpenJPH, libpng, libtiff, libwebp, compression libraries and a C++ runtime. Its RECORD included no licence texts. The Studio source supplies the OCP and OCCT texts. A distributor bundling this wheel must also obtain the corresponding component notices and meet whichever upstream terms apply. FreeImage offers FIPL or GPL choices, and LibRaw offers LGPL 2.1 or CDDL 1.0. These additional notices, matching sources and any codec-specific conditions require review for the actual binary set before a bundled public distribution. [FreeImage terms](https://freeimage.sourceforge.io/license.html) · [LibRaw terms](https://www.libraw.org/about#license)
* **2D and solid geometry.** Shapely 2.2.0 is BSD-3-Clause. Its macOS wheel includes GEOS 3.14.1 and `LICENSE_GEOS` identifying LGPL 2.1. Preserve those notices, source access and library-replacement rights when distributing the libraries. Manifold 3.5.5 carries Apache 2.0 and an AUTHORS file. ezdxf 1.4.5 uses MIT. Retain the FontTools external licence file when distributing its font tools. [Shapely](https://github.com/shapely/shapely) · [GEOS source](https://github.com/libgeos/geos) · [Manifold licence](https://github.com/elalish/manifold/blob/master/LICENSE) · [ezdxf licence](https://github.com/mozman/ezdxf/blob/master/LICENSE)
* **Numerics, image, serial and web services.** NumPy's distribution carries component-specific notices alongside its BSD and other permissive licences. Pillow uses MIT-CMU and its binary wheel contains separately licensed image codecs and font/text libraries. Preserve the actual wheel's complete licence bundle, including any attribution required by the included FreeType and JPEG components. pySerial uses BSD terms. Flask and its supporting libraries retain their upstream notices. Cheroot and cryptography carry separate terms, and a cryptography wheel can include OpenSSL. [NumPy licences](https://github.com/numpy/numpy/blob/main/LICENSE.txt) · [Pillow licence](https://pillow.readthedocs.io/en/stable/about.html#license) · [pySerial licence](https://pyserial.readthedocs.io/en/latest/appendix.html#license) · [cryptography installation](https://cryptography.io/en/latest/installation/)
* **MCP.** The resolved FastMCP and FastMCP Slim advertise Apache 2.0. The MCP SDK advertises MIT. The dependency set includes certifi's Mozilla trust bundle under MPL 2.0. Preserve the MPL notice and comply with its source-availability provisions if distributing the covered material. Other transitive licences are listed in the inventory. The optional service is installed independently of the Studio wheel. [FastMCP release](https://pypi.org/project/fastmcp/3.4.11/) · [certifi](https://github.com/certifi/python-certifi) · [MPL 2.0](https://www.mozilla.org/en-US/MPL/2.0/)

To refresh the inventory in a build environment, run `python -m pip install --dry-run --ignore-installed --report resolved.json ".[web,step,mcp]"`. Use the target OS, architecture and Python for each build, inspect the actual archives, and retain licence files even when a package's metadata reports a single permissive identifier. The recorded resolver output describes a specific platform and date.
